# Third-party components

## TorrServer

MediaStream Player can download and run an unmodified TorrServer executable on the user's Android device for local playback.

- Project: https://github.com/YouROK/TorrServer
- License: GNU General Public License v3.0
- Source code: https://github.com/YouROK/TorrServer

The TorrServer executable is obtained from the release metadata published by the TorrServe project and is not stored in this repository.
